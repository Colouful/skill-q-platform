# 项目概述

## 项目定位

一个基于 Next.js + TypeScript 的 SSR/SSG Web 应用。

## 技术栈

| 领域 | 技术 | 说明 |
|------|------|------|
| UI 框架 | React ^19.0.0 | 应用基础框架（由 Next.js 运行时承载） |
| 类型系统 | TypeScript ^5 | 强制使用；详见 `02-编码规范.md` |
| 构建工具 | Next.js ^16.2.1 | `next build` 生产构建，开发期使用 Turbopack |
| 路由管理 | Next App Router | 文件系统路由，页面与 API 同构在 `src/app/` |
| 状态管理 | React Context | 优先使用轻量 Provider 模式，不引入额外全局状态库 |
| 组件库 | @base-ui/react ^1.3.0 | 作为 UI 原语层，结合本项目组件封装 |
| 样式方案 | Tailwind CSS v4 + 全局 CSS 变量 | 强制使用 `src/app/globals.css` 的主题变量体系 |
| HTTP 请求 | fetch（封装） | 通过 `src/lib/client-api.ts` 统一请求与错误返回格式 |
| 数据访问 | Prisma ^7.5.0 + MariaDB ^3.5.2 | 服务端数据访问与模型管理 |
