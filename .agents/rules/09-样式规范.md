# 样式规范

## 基础原则

- 使用 Tailwind CSS v4 作为主样式方案。
- 全局样式与主题变量集中在 `src/app/globals.css`。
- 优先使用设计变量（`var(--*)`）表达颜色、阴影、圆角与字号，避免硬编码。
- 通用视觉能力（按钮态、主题态、动画）优先复用既有 class 体系。

## 主题/CSS 变量

- 主题通过 `html[data-theme="..."]` 切换，不直接在组件里写主题分支常量。
- 核心变量统一放在 `:root` 与主题作用域（如 `.dark`、`html[data-theme="ink"]`）。
- 变量命名沿用现有前缀：`--pixel-*`、`--hub-*`、`--background` 等，禁止无语义新前缀。
- Tailwind `@theme inline` 与 CSS 变量保持映射一致，保证原子类与主题变量联动。

## 暗色/浅色模式

- 使用 `.dark` 变量覆盖模式，不通过散落的组件级手工判断切换颜色。
- 主题切换时允许平滑过渡，但需遵守可访问性和性能约束（优先减少重排重绘）。
- 如用户系统设置了减少动态效果（`prefers-reduced-motion`），动画需降级或关闭。

## 全局样式

```text
src/app/globals.css
```

- `globals.css` 负责：Tailwind 引入、主题变量、全局动画、基础元素样式层。
- 业务组件优先通过 Tailwind 类组合；仅在必须时扩展全局 class。
- 若新增全局变量，需同步评估对现有主题（pixel/apple/sketch/ink）的影响。
