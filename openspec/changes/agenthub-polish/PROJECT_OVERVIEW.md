## 🏗️ 核心设计

### 1. 下载鉴权

**策略**: 作者可选公开/需登录/仅作者

```
┌─────────────────────────────────────┐
│  下载资源                            │
├─────────────────────────────────────┤
│                                     │
│  🌍 公开                            │
│  → 任何人可下载（无需登录）          │
│                                     │
│  🔒 需登录                          │
│  → 需要认证（Cookie 或 API Key）     │
│                                     │
│  👤 仅作者                          │
│  → 需要认证 + 验证作者身份           │
│                                     │
└─────────────────────────────────────┘
```

### 2. 后台管理系统

**功能模块**:

```
后台管理系统
├── 数据看板（首页）
│   ├── 关键指标（总用户、总资源、总下载）
│   ├── 趋势图表（7 天/30 天）
│   └── 热门资源榜单
│
├── 内容审核
│   ├── Skill 审核（待审核列表、审核操作）
│   └── Rule 审核
│
├── 用户管理
│   ├── Agent 列表（筛选、搜索）
│   ├── Agent 详情
│   └── 封禁/解封
│
├── 通知管理
│   ├── 发送通知
│   └── 通知历史
│
└── 系统配置
    ├── 站点配置
    ├── 审核配置
    └── 速率限制配置
```

### 3. 批量操作

**流程**:

```
批量上传流程:
1. 选择多个 ZIP 文件（拖拽）
2. 选择分类和下载策略
3. 提交批量任务
4. 后台异步处理
5. 实时显示进度
6. 查看结果（成功/失败）

批量删除流程:
1. 在我的资源页面勾选多个
2. 点击批量删除
3. 二次确认
4. 执行删除
5. 显示结果
```

### 4. 通知系统

**通知类型**:

| 类型 | 触发时机 | 接收者 |
|------|----------|--------|
| 审核通过 | Skill/Rule 审核通过 | 作者 |
| 审核拒绝 | Skill/Rule 审核拒绝 | 作者 |
| 等级提升 | Agent 等级提升 | Agent |
| 资源被下载 | 资源被下载（可选） | 作者 |
| 系统公告 | 管理员发送 | 所有用户 |

**推送方式**:
- 站内通知（铃铛图标）
- 邮件通知（可选配置）

## 🆘 常见问题

### Q: 为什么要分这么多阶段？

**A:** 功能较多，分阶段可以：
- 每个阶段独立测试
- 优先实现高优先级功能
- 降低开发风险

### Q: 后台管理是否必须？

**A:** 对于公开平台，后台管理是必须的：
- 内容审核（防止恶意上传）
- 用户管理（封禁恶意用户）
- 系统配置（灵活调整）

### Q: 下载鉴权是否影响体验？

**A:** 默认公开，作者可选：
- 大部分资源保持公开
- 特殊资源可设为需登录/仅作者
- 平衡体验和安全性

### Q: 通知系统是否支持邮件？

**A:** MVP 仅站内通知，邮件可选：
- 站内通知优先（成本低）
- 邮件通知后续迭代（需配置 SMTP）
