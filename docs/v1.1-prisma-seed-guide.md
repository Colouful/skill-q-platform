# V1.1 Prisma / Seed 指南

## 数据库准备

`skill-q-platform` 使用 Prisma(数据库 ORM) 管理 Hub 数据模型。执行数据库相关命令前请确认：

1. `.env` 中数据库连接可用。
2. 本地 `node_modules` 已存在。
3. 不在生产库上直接执行 `db:push`。

## Prisma Validate

```bash
./node_modules/.bin/prisma validate --schema prisma/schema.prisma
```

V1.1 验收结果：通过。

## Migration 状态检查

当前目录存在：

```text
prisma/migrations/migration_lock.toml
```

建议在正式环境使用：

```bash
npx prisma migrate status --schema prisma/schema.prisma
```

本轮未新增 migration，不自动执行数据库变更。

## Prisma Client 生成

```bash
npm run prisma:generate
```

对应脚本：

```bash
npx prisma generate
```

项目还包含 postinstall(安装后脚本)：

```bash
node scripts/prisma-generate-if-needed.cjs --postinstall
```

## 常见失败原因

1. 数据库连接不可用：检查 `.env`。
2. Prisma Client 未生成：执行 `npm run prisma:generate`。
3. seed 缺少 published 资产：执行 seed 后重新验证。
4. checksum 不一致：不要修改 published asset content，请发布新版本。
5. Turbopack 下 API route 404：本地 Hub API 建议用 webpack dev mode(webpack 开发模式)验证。

## 回滚建议

1. 不直接修改已发布资产正文。
2. schema 变更通过 migration 回滚，不手工改库。
3. seed 误写入时优先用新版本覆盖，不破坏历史版本。
4. V1.1 smoke 前建议先备份本地数据库。
