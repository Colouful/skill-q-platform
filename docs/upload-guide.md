# 上传说明（ZIP / 附件）

## 限制

- **大小**：以服务端与环境变量配置为准（例如单文件上限 MB 级）。
- **类型**：优先允许 `.zip`；其它类型以产品配置为准。
- **编码**：文件名与元数据使用 UTF-8；数据库存储若使用 `utf8mb3`，请避免依赖需要四字节的 Emoji 作为唯一键。

## 流程建议

1. 在创建或编辑技能时选择文件并上传。
2. 等待上传完成后再保存表单，避免引用未完成的资源 URL。
3. 大文件建议在稳定网络环境下操作；失败时可重试。

## 安全

- 不要上传可执行文件并期望服务端直接执行。
- 敏感内容请勿放入公开技能包。
