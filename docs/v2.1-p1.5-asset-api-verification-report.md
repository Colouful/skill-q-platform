## 7. 多级 API 路由是否符合 Next.js App Router

符合。

路由目录采用 Next.js App Router(App 路由)约定：

- 静态段使用普通目录。
- 动态段使用 `[assetId]` / `[versionId]`。
- 每个 API(API 接口)端点对应 `route.ts`。
- 多级 POST 动作使用子目录 `publish/route.ts`、`deprecate/route.ts`、`archive/route.ts`。

已执行：

```bash
npx next typegen
./node_modules/.bin/tsc --noEmit
```

结果均通过，说明 route types(路由类型)可生成且 TypeScript(类型检查)通过。

## 8. service 是否被 route 引用

是。

核验命令：

```bash
rg -n "AssetGovernanceService|AssetQueryService|AssetVersionService|hubSuccess|hubException" src/app/api/hub/admin src/server/hub/asset-*.ts
```

结果显示：

- `GET /api/hub/admin/assets` 调用 `AssetQueryService.list`。
- `POST /api/hub/admin/assets` 调用 `AssetGovernanceService.createDraft`。
- `GET /api/hub/admin/assets/:assetId` 调用 `AssetQueryService.detail`。
- `PATCH /api/hub/admin/assets/:assetId` 调用 `AssetGovernanceService.updateDraft`。
- `GET /api/hub/admin/assets/:assetId/versions` 调用 `AssetVersionService.list`。
- `POST /api/hub/admin/assets/:assetId/versions` 调用 `AssetVersionService.create`。
- `GET /api/hub/admin/assets/:assetId/versions/:versionId` 调用 `AssetVersionService.detail`。
- `publish` / `deprecate` / `archive` 路由分别调用对应 service(服务)方法。

route(API 路由)只做请求解析、调用 service(服务)、返回 ApiResponse(统一响应)。

## 10. Asset 管理 API 验证结果

Asset 管理 API(资产管理接口)验证通过。

覆盖规则：

1. 创建 draft asset(草稿资产)成功。
2. slug 重复时报错。
3. kind(类型)非法时报错。
4. asset(资产)列表分页。
5. asset(资产)列表 keyword(关键词)搜索。
6. asset(资产)列表按 kind(类型)筛选。
7. asset(资产)列表按 status(状态)筛选。
8. asset(资产)详情返回版本摘要。
9. draft asset(草稿资产)可更新。
10. published asset(已发布资产)不允许更新基础信息。
11. archived asset(已归档资产)不允许更新。
12. 创建 asset version(资产版本)成功。
13. version(版本号)重复时报错。
14. content(正文)为空时报错。
15. 创建 version(版本)自动生成 checksum(校验和)。
16. 创建 version(版本)自动生成 contentSize(内容大小)。
17. 发布 draft version(草稿版本)成功。
18. 发布后 `immutable=true`。
19. 发布后 `status=published`。
20. published version(已发布版本)不允许修改 content(正文)。
21. published version(已发布版本) checksum(校验和)稳定。
22. draft version(草稿版本)可修改 content(正文)。
23. deprecated version(已废弃版本)不改变 checksum(校验和)。
24. archived asset(已归档资产)不允许新增 version(版本)。
25. API(API 接口)不返回 `sourceCode` / `rawPrompt` / `rawResponse` / 绝对路径。
