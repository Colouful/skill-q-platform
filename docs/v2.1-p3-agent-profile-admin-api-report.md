## 5. Agent Profile 创建规则

`POST /api/hub/admin/agent-profiles` 支持创建 draft(草稿) Agent Profile(智能体画像)。

规则：

- `slug` 必填。
- `name` 必填。
- `version` 必填。
- `slug + version` 必须唯一。
- 默认 `status=draft`。
- 创建时不允许直接 published(已发布)。
- content(内容)必须通过安全策略校验。
- 自动补齐默认 `deniedTools`。
- 自动补齐默认 `approvalPolicy`。
- 自动补齐默认 `contextScope`。
- 自动计算 checksum(校验和)。
- 不允许 content(内容)中包含 `sourceCode` / `rawPrompt` / `rawResponse` / 绝对路径。
- 重复 `slug + version` 返回 `AGENT_PROFILE_VERSION_ALREADY_EXISTS`。

## 6. Agent Profile 更新规则

`PATCH /api/hub/admin/agent-profiles/:profileId` 支持更新 draft(草稿) / rejected(已驳回) Agent Profile(智能体画像)。

规则：

- 只允许更新 `name`、`description`、`content`、`ownerTeamId`、`ownerUserId`。
- 不允许修改 `slug`。
- 不允许修改 `version`。
- published(已发布)、deprecated(已废弃)、archived(已归档)状态不允许直接修改。
- archived(已归档)状态返回 `AGENT_PROFILE_ARCHIVED`。
- 更新 content(内容)时重新校验安全策略。
- 更新 content(内容)时重新计算 checksum(校验和)。
- 违规返回 `AGENT_PROFILE_UPDATE_NOT_ALLOWED`。

## 7. Agent Profile 发布规则

`POST /api/hub/admin/agent-profiles/:profileId/publish` 支持发布 draft(草稿) / reviewing(审核中) Agent Profile(智能体画像)。

规则：

- 只能发布 draft(草稿) / reviewing(审核中)状态。
- content(内容)必须存在。
- checksum(校验和)必须存在。
- 发布时重新计算 checksum(校验和)。
- `deniedTools` 必须包含 `upload-source` / `deploy` / `push` / `merge`。
- `contextScope.allowSourceCode` 必须为 `false`。
- `contextScope.allowAbsolutePath` 必须为 `false`。
- `approvalPolicy.beforePush` 必须为 `true`。
- `approvalPolicy.beforeMerge` 必须为 `true`。
- `approvalPolicy.highRiskAlwaysManual` 必须为 `true`。
- 发布后 `status=published`。
- 写入 `publishedAt`。
- 写入 `publishedBy=system`。
- published(已发布)后不允许修改 content(内容)。

## 8. Agent Profile 废弃规则

`POST /api/hub/admin/agent-profiles/:profileId/deprecate` 支持废弃 published(已发布) Agent Profile(智能体画像)。

规则：

- 只能废弃 published(已发布)状态。
- deprecated(已废弃)后旧 lock(锁文件)可继续使用。
- deprecated(已废弃)不应被新 Manifest(清单)默认选择。
- 不删除 content(内容)。
- 不改变 checksum(校验和)。
- 写入 `deprecatedAt`。

## 9. Agent Profile 归档规则

`POST /api/hub/admin/agent-profiles/:profileId/archive` 支持归档 Agent Profile(智能体画像)。

规则：

- archived(已归档)后不允许修改。
- archived(已归档)后不允许被新 Manifest(清单)绑定或默认选择。
- 不删除 content(内容)。
- 不改变 checksum(校验和)。
- 写入 `archivedAt`。

## 10. Agent Profile 安全策略

强制安全策略：

- `deniedTools` 必须包含 `upload-source`。
- `deniedTools` 必须包含 `deploy`。
- `deniedTools` 必须包含 `push`。
- `deniedTools` 必须包含 `merge`。
- `contextScope.allowSourceCode=false`。
- `contextScope.allowAbsolutePath=false`。
- `approvalPolicy.beforePush=true`。
- `approvalPolicy.beforeMerge=true`。
- `approvalPolicy.highRiskAlwaysManual=true`。
- `modelPolicy.tokenBudget` 必须为正数。
- `defaultExecutor` 必须为 `cursor` / `codex` / `claude-code`。
- 请求和 content(内容)不允许包含 `sourceCode` / `rawPrompt` / `rawResponse` / 绝对路径。

`POST /api/hub/admin/agent-profiles/:profileId/validate` 返回：

- `valid`：是否通过。
- `errors`：错误列表。
- `warnings`：当前为空数组，预留给后续弱约束。

## 11. Agent Profile checksum 策略

checksum(校验和)策略：

- 创建 Agent Profile(智能体画像)时基于规范化 content(内容)生成 `sha256:` checksum(校验和)。
- 更新 content(内容)后重新计算 checksum(校验和)。
- 发布前校验 checksum(校验和)存在。
- 发布时重新计算 checksum(校验和)。
- deprecated(已废弃)和 archived(已归档)不改变 checksum(校验和)。

## 12. Agent Profile Export 兼容性说明

现有 `GET /api/hub/agent-profiles/:slug/export` 未改变路径和响应结构。

兼容要求保持：

- 响应继续包含 `slug`。
- 响应继续包含 `version`。
- 响应继续包含 `content`。
- 响应继续包含 `checksum`。
- 只导出 published(已发布) Agent Profile(智能体画像)。
- draft(草稿) Agent Profile(智能体画像)不允许 export(导出)。
- archived(已归档) Agent Profile(智能体画像)不允许 export(导出)。

deprecated(已废弃)策略说明：

- deprecated(已废弃)后旧 lock(锁文件)可继续使用的策略保留在治理语义中。
- 当前 V1.1 Export(导出)接口只查 published(已发布)状态，因此 deprecated(已废弃)不会被新导出命中。
- 后续如需“按旧 lock 精确导出 deprecated(已废弃)版本”，应新增显式兼容接口或 lock-aware(锁感知)查询，不改变 V1.1 默认 Export(导出)行为。
