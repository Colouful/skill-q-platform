# V2.1 已知问题清单

## 1. 审计日志当前为内存占位

AuditLog(审计日志) 当前通过 `AuditLogService(审计占位服务)` 写入内存数组。服务重启后记录会丢失，仅用于 V2.1 P5 最小审核闭环验证。

生产化建议：

- 新增 AuditLog(审计日志) Prisma model(数据模型)。
- 新增 migration(数据库迁移)。
- 将 `AuditLogService` 改为持久化写入。

## 2. 未实现复杂 RBAC

V2.1 未实现复杂 RBAC(基于角色的访问控制)。当前 admin API(后台管理接口) 主要验证资产治理业务规则，不包含细粒度权限矩阵。

## 3. 未实现复杂审批队列

V2.1 仅实现：

- submit-review(提交审核)。
- reject(驳回)。
- publish(发布)。
- 审计占位。

未实现审批人、审批队列、会签、转交、超时提醒等复杂流程。

## 4. 未实现组织架构

V2.1 保留 ownerOrgId(组织标识)、ownerTeamId(团队标识)、ownerUserId(用户标识) 等字段能力，但未实现复杂组织架构管理页面和组织权限继承。

## 5. 未实现 AI 工程资产生成器

V2.1 不包含 Asset Factory(AI 工程资产生成器)。后续如进入 V2.2 或更后阶段，需要单独设计生成任务、输入约束、安全隔离和审核流。

## 6. 未实现 OpenClaw / 钉钉

V2.1 未实现 OpenClaw(开放执行器) 和钉钉机器人入口，也未实现远程任务调度。

## 7. 未实现真实执行器编码

V2.1 未实现真实 Codex(代码智能体)、Cursor(编辑器)、Claude Code(代码工具) 自动编码。Agent Profile(智能体配置) 仅作为治理资产被管理和导出。

## 8. 历史 lint warning

`npm run lint` 当前通过，但仍有 44 个历史 warning(警告)，主要包括：

- React hook(React 钩子) set-state-in-effect(副作用中同步设置状态)。
- unused-vars(未使用变量)。
- no-img-element(未使用 Next Image 组件)。
- 测试里的 no-explicit-any(显式 any 类型)。

当前无 lint error(代码规范错误)。

## 9. 当前 HubRepository 仍为内存实现

V2.1 测试闭环使用 `defaultHubRepository(默认资产中心仓储)` 和 seed(种子数据) 完成。当前管理 API(应用程序接口) 的运行态数据仍以 HubRepository(资产中心仓储) 内存实现为主。

生产化建议：

- 将 P1/P2/P3/P5 服务接入 Prisma Repository(数据库仓储)。
- 保持 V1.1 Hub API(资产中心接口) 响应契约不变。
- 补充数据库集成测试。

## 10. 生产化需要补充持久化审计表

生产化前建议补充：

- `AuditLog` Prisma model(数据模型)。
- 审计表索引：targetType(目标类型)、targetId(目标标识)、action(操作)、createdAt(创建时间)。
- 审计日志分页查询。
- 审计日志 retention(保留策略)。
- 审计日志导出能力。

## 11. draft 直接发布兼容策略仍保留

为保护 P1/P2/P3 已有 API(应用程序接口) 回归，服务端 publish(发布) 仍兼容 draft(草稿) 直接发布。P5 页面主路径已经改为 submit-review(提交审核) 后再 publish(发布)。

如后续要求强制审核后发布，需要单独收紧 publish(发布) 服务状态校验，并同步调整既有测试。
