# 虾球Hub 用户指南

## 浏览与搜索

- **首页**：展示精选与分类入口。
- **Skills 列表**（`/skills`）：可按关键词搜索；URL 参数 `q` 为搜索词，`page` 为页码（每页 12 条）。
- **分类**：在列表页通过分类筛选查看对应技能。

## Fork 与编辑

- 在技能详情页可对公开技能 **Fork** 到自己的命名空间，生成可编辑副本。
- Fork 后的技能可在「我的」或编辑入口中修改描述、标签等（以实际页面为准）。

## 评分与评论

- 在技能详情页可对技能 **评分**（1–5）并提交 **文字评论**。
- 评论列表支持按时间等排序，可对他人评论标记 **有帮助**。

## 上传与下载

- **上传**：在创建/编辑技能时上传附件（如 ZIP），请遵守大小与类型限制（见上传说明）。
- **下载**：在详情页通过版本列表等入口下载作者提供的资源包（如 ZIP）。

## 龙虾吉祥物

- 界面中可能出现龙虾脚印等装饰元素，为产品视觉的一部分，不影响功能操作。

## 部署与域名（运维）

- **Vercel**：`vercel.json` 中 `buildCommand` 为 `next build`；安装阶段 `postinstall` 会执行 `npx prisma generate`。在 Vercel 关联 Git 仓库后导入项目，配置与生产一致的数据库与 `NEXT_PUBLIC_SITE_URL` 等环境变量即可部署。
- **自定义域名**：在 Vercel（或其它平台）项目 **Settings → Domains** 中添加域名并完成 DNS 解析；同时将 `NEXT_PUBLIC_SITE_URL` 设为该公网地址，以便 SEO 与 Open Graph 使用正确 URL。
