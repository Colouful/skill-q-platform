# V2.2 P2 AuditLog 审计日志持久化实施报告

## 1. P2 目标

V2.2 P2 的目标是把 V2.1 / V2.2 P1 中的 AuditLog(审计日志) 内存占位升级为 Prisma(数据库 ORM) 持久化基础能力，同时保持 V2.1 API(接口)、页面和审核状态流转语义不变。

本轮完成：

1. 新增 `HubAuditLog` Prisma model(数据库模型)。
2. 新增独立 migration(数据库迁移)。
3. 完善 `AuditLogRepositoryPort`(审计日志仓储接口)。
4. 新增 `PrismaAuditLogRepository`(Prisma 审计日志仓储)。
5. 保留 `InMemoryHubRepositoryAdapter`(内存仓储适配器) 的 AuditLog 能力。
6. 将 `AuditLogService`(审计日志服务) 改为可注入 Repository(仓储)。
7. 将 `ReviewWorkflowService`(审核流程服务) 的审计写入改为等待写入完成，不再默默忽略。
8. 保持 `/api/hub/admin/audit-logs` 查询路径不变。
9. 增加 AuditLog 持久化、隐私、API 和审核流测试。

## 3. 新增 Prisma model

新增模型：

```prisma
model HubAuditLog {
  id            String   @id @db.VarChar(36)
  targetType    String   @db.VarChar(80)
  targetId      String   @db.VarChar(191)
  targetSlug    String?  @db.VarChar(191)
  targetVersion String?  @db.VarChar(80)
  action        String   @db.VarChar(80)
  statusFrom    String?  @db.VarChar(80)
  statusTo      String?  @db.VarChar(80)
  operatorId    String?  @db.VarChar(191)
  operatorName  String?  @db.VarChar(191)
  operatorType  String?  @db.VarChar(80)
  reason        String?  @db.Text
  note          String?  @db.Text
  metadata      Json?
  requestId     String?  @db.VarChar(191)
  createdAt     DateTime @default(now())

  @@index([targetType, targetId, createdAt])
  @@index([action, createdAt])
  @@index([operatorId, createdAt])
  @@index([createdAt])
  @@map("hub_audit_log")
}
```

说明：

1. 使用 `HubAuditLog` 保持 Prisma delegate(Prisma 委托) 为 `hubAuditLog`。
2. 数据库表名映射为 `hub_audit_log`，与当前 Hub 表命名风格一致。
3. 未删除、重命名任何既有模型字段。

## 6. AuditLogService 改造说明

`AuditLogService` 已从模块级内存数组改为依赖 `AuditLogRepositoryPort`：

1. 默认 memory(内存) 模式使用共享 `InMemoryHubRepositoryAdapter`，保持现有测试和页面调用方式可用。
2. 当 `HUB_REPOSITORY_MODE=prisma` 时，懒加载 Prisma Client(Prisma 客户端) 并使用 `PrismaAuditLogRepository`。
3. 提供 `createAuditLog`。
4. 保留 `append` 兼容 P5 旧调用语义。
5. 提供 `listAuditLogs`。
6. 保留 `list` 兼容 `/api/hub/admin/audit-logs` 和旧测试。
7. 写入失败会返回明确中文错误，不吞掉关键审计失败。

## 7. ReviewWorkflowService 接入说明

`ReviewWorkflowService` 的以下动作已等待审计日志写入完成：

1. Asset Version submit-review(提交审核)。
2. Asset Version reject(驳回)。
3. Asset Version publish(发布)。
4. Manifest Version submit-review。
5. Manifest Version reject。
6. Manifest Version publish。
7. Agent Profile submit-review。
8. Agent Profile reject。
9. Agent Profile publish。

状态流转语义未改变；只是相关方法从同步返回调整为 `async`(异步) 返回，route(路由) 已补充 `await`，API 响应结构不变。

## 9. 隐私过滤策略

新增 `assertSafeAuditLogPayload`，对 metadata(元数据) 递归检查，采用拒绝写入策略，不悄悄删除字段。

禁止写入：

1. `sourceCode`
2. `sourceContent`
3. `fileContent`
4. `rawPrompt`
5. `rawResponse`
6. `absolutePath`
7. `apiKey`
8. `password`
9. `token`
10. `secret`
11. `.env` 内容
12. `/Users/` 路径
13. 其他绝对路径

隐私错误码：

```text
AUDIT_LOG_PRIVACY_VIOLATED
```
