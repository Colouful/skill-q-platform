# V2.1 验收报告

## 1. V2.1 目标

V2.1 目标是将 skill-q-platform 从“Hub API(资产中心接口) 最小闭环”升级为“团队可用的资产治理平台”，覆盖 Asset(资产)、Manifest(清单)、Agent Profile(智能体配置)、Hub(资产中心) 页面、发布流程与审核占位，并继续保护 V1.1 Hub API(资产中心接口) 与 br-ai-spec(规范工具) 兼容契约。

## 2. V2.1 范围

V2.1 已覆盖：

- P0 数据模型与契约保护。
- P0.5 Prisma migration(数据库迁移) / Generated Client(生成客户端) / seed(种子数据) 策略固化。
- P1 Asset(资产) 管理 API(应用程序接口)。
- P1.5 Asset API(资产接口) 落盘与真实路由核验。
- P2 Manifest(清单) 管理 API(应用程序接口)。
- P3 Agent Profile(智能体配置) 管理 API(应用程序接口)。
- P4 Hub(资产中心) 页面。
- P5 发布流程与审核占位。
- P6 测试与验收。

## 3. V2.1 不包含内容

V2.1 不包含：

- AI 工程资产生成器。
- 真实 Codex(代码智能体) 自动编码。
- 真实 Cursor(编辑器) / Claude Code(代码工具) 自动编码。
- OpenClaw(开放执行器)。
- 钉钉机器人。
- 复杂组织架构。
- 复杂 RBAC(基于角色的访问控制)。
- 复杂报表。
- 自动 PR(拉取请求) / push(推送) / merge(合并)。

## 14. 隐私与安全验收结果

通过：

- 不返回 sourceCode(源码)。
- 不返回 sourceContent(源码内容)。
- 不返回 fileContent(文件内容)。
- 不返回 rawPrompt(原始提示)。
- 不返回 rawResponse(原始响应)。
- 不返回 `/Users/` 绝对路径。
- Runtime Feedback(运行反馈) 仍拒绝敏感 payload(载荷)。
- Agent Profile(智能体配置) 默认禁止 upload-source(上传源码)。
- Agent Profile(智能体配置) 默认禁止 deploy(部署)、push(推送)、merge(合并)。
- Agent Profile(智能体配置) 默认禁止 allowSourceCode(允许源码) 和 allowAbsolutePath(允许绝对路径)。
- published(已发布) 资源不可直接修改。

说明：隐私关键词扫描命中测试用例、隐私拦截器和安全策略字段定义，不代表运行输出泄露。契约测试和页面测试均覆盖敏感字段拒绝或不展示。

当前仍有历史 lint warning(代码规范警告)，主要来自：

- 既有 React hook(React 钩子) set-state-in-effect(副作用中同步设置状态)。
- 既有 unused-vars(未使用变量)。
- 既有 no-img-element(图片标签)。
- 既有测试 no-explicit-any(显式 any 类型)。

这些 warning(警告) 不阻断 V2.1 验收。当前 lint(代码规范检查) 无 error(错误)。

`npm run build` 中出现 Next.js(框架) middleware(中间件) 文件约定 deprecated(已弃用) warning(警告)，不影响构建成功。

- 当前页面 smoke test(冒烟测试) 不等价于完整浏览器 E2E(端到端测试)。
